# 글로벌 스크리닝 60 — 모의 포트폴리오 자동 트래킹

**사이트: https://jungjun2016-create.github.io/portfolio/**

나스닥 시총 Top 300 · 한국 Top 100 · 홍콩 Top 300에서 차트를 1차 기준으로 고르고
밸류·성장을 가점으로 얹어 국가별 20종목씩 60종목을 담은 $100,000 모의 포트폴리오.
V3 개시 2026-08-21.

## 자동 갱신
GitHub Actions가 **평일 07:30 / 17:30 KST**에 Yahoo Finance에서 종가·환율·벤치마크를 받아
스냅샷을 추가하고 `index.html`을 다시 만들어 커밋한다. 월요일 회차엔 주봉 60주 차트도 갱신한다.

즉시 갱신이 필요하면 Actions 탭 → `포트폴리오 갱신` → **Run workflow**.
(`weekly` 체크 시 주봉 차트까지, `rebalance` 체크 시 리밸런싱까지)

## 자동 리밸런싱 (월요일 아침)
월요일 오전 회차에서만 `build/rebalance.py`가 돈다. **필요할 때만 교체한다** —
훼손 판정을 통과한 종목이 없으면 차트 점수만 갱신하고 포트폴리오는 건드리지 않는다.

**훼손 판정** — Yahoo 주봉 60주로 계산한다. 아래 점수 합이 4점 이상이면 교체 대상.

| 조건 | 점수 |
|---|---|
| 현재가 < 40주선 | +2 |
| 현재가 < 20주선 | +1 |
| 52주 고점 대비 -25% 이하 (-15% 이하면 +1) | +2 |
| 12주 모멘텀 -10% 이하 (0% 이하면 +1) | +2 |
| 40주선 하락 전환 | +1 |

**후보 하드 게이트** — 현재가 > 20주선 > 40주선 / 52주 고점 대비 -15% 초과 /
12주 모멘텀 > 0 / 시총 10억 달러 이상. 통과한 후보를 차트 점수 순으로 세우고,
교체 대상보다 **10점 이상** 앞설 때만 실제로 바꾼다.

**상한** — 국가당 한 주 최대 **10종목**. 교체는 자리 바꾸기라서 종목 수·국가별 구성은 그대로다.
매도 종목의 현재 평가액(USD)을 그대로 신규 종목에 넣기 때문에 교체 순간 총 평가액이 변하지 않고,
누적 수익률 곡선도 끊기지 않는다. 신규 종목에는 `since`(편입 스냅샷)와 `fx_entry`(편입 시점 환율)를
달아 스파크라인과 USD 수익률이 이전 종목 이력을 물려받지 않게 한다.

기준값은 환경변수로 조정한다 — `REBAL_MAX_PER_MARKET`(기본 10), `REBAL_DAMAGE_MIN`(4),
`REBAL_MIN_SCORE_GAIN`(10), `REBAL_MIN_MCAP_B`(1.0), `REBAL_CAND_DEPTH`(60).

로컬에서 판정만 확인하려면 `python3 build/rebalance.py --dry-run --force`.

## 구성
| 경로 | 역할 |
|---|---|
| `data/state.json` | 정본 데이터 — meta / holdings 60 / snapshots / details |
| `data/universe.json` | 리밸런싱 후보 유니버스 (시총 상위 300 / 100 / 300) |
| `build/fetch_prices.py` | 시세 수집 → 스냅샷 추가 (`--weekly`로 주봉도) |
| `build/rebalance.py` | 훼손 판정 → 필요하면 종목 교체 |
| `build/refresh_universe.py` | 유니버스 재수집 (분기 1회 수동) |
| `build/render.py` | `state.json` → `index.html` |
| `build/css.txt`, `build/app.js` | 스타일 / 차트·상세 패널 스크립트 |
| `.github/workflows/update.yml` | 스케줄 + 수동 실행 |
| `index.html` | **산출물. 직접 편집하지 말 것** |

## 안전장치
- 60종목 전부 양수 가격일 때만 저장
- 직전 종가 대비 **50% 이상 급변**이면 데이터 오류로 보고 저장 중단
- 같은 날짜 재실행은 마지막 스냅샷만 덮어쓰고 과거 이력은 지우지 않음 (리밸런싱 기록도 보존)
- 리밸런싱은 진단 데이터를 하나도 못 받으면 아무것도 바꾸지 않고 종료
- Yahoo가 데이터센터 IP를 429로 막는 데 대비해 쿠키+crumb → 일괄 quote → 개별 chart → stooq 4단 폴백

## 수동으로 손봐야 하는 것
재무제표·사업부문·비즈니스 모델·뉴스(`details`)는 자동화 대상이 아니다.
Actions 탭의 `상세 데이터 수집`을 수동 실행하거나 `data/state.json`을 직접 교체한다.
자동 편입된 종목은 상세가 비어 있으니 교체가 있었던 주에는 한 번 돌려주는 게 좋다.

> 실제 투자 포트폴리오가 아니라 스크리닝 모델을 추적하기 위한 모의 포트폴리오다.
